# 🏥 Hospital Emergency Room Analytics Dashboard | Excel

## 📌 Project Overview

This project presents an interactive Hospital Emergency Room Analytics Dashboard developed in Microsoft Excel.

The dashboard analyzes emergency-room activity to understand patient volumes, waiting times, admission patterns, patient demographics, satisfaction levels and departmental referrals.

The objective was to transform patient-level emergency-room data into an interactive analytical dashboard that enables healthcare stakeholders to quickly identify operational patterns and potential service bottlenecks.

> **Disclaimer:** This project was developed for data analytics portfolio and learning purposes. If using a synthetic dataset, all figures should be treated as simulated and not as actual hospital performance data.

---

## 📊 Dataset

The dataset contains patient-level emergency-room records.

Key fields analyzed include:

- Patient ID
- Patient Admission Date
- Patient Admission Time
- Patient Gender
- Patient Age
- Patient Race
- Department Referral
- Patient Admission Status
- Patient Satisfaction Score
- Patient Wait Time

# 🔎 Business Questions Addressed

The dashboard was designed to answer questions such as:

1. How many patients visited the emergency room?
2. How is patient volume changing over time?
3. What is the average patient waiting time?
4. What proportion of patients are admitted?
5. What is the average patient satisfaction score?
6. Which age groups account for the most ER visits?
7. What is the gender distribution of ER patients?
8. Which departments receive the most referrals?
9. Are there identifiable patterns in waiting time and patient satisfaction?
